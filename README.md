# Mon Coffre

Gestionnaire de mots de passe pour Windows. Tes données sont chiffrées et restent **uniquement sur ton ordinateur** : rien n'est envoyé sur Internet.

## Installer
1. Va dans l'onglet **Releases** et télécharge `MonCoffre.exe`.
2. Double-clique dessus. Au premier lancement, tu crées ton mot de passe maître.
3. Si Windows affiche « Windows a protégé votre ordinateur » : clique sur « Informations complémentaires », puis « Exécuter quand même ».

⚠️ Si tu oublies ton mot de passe maître, tes données sont perdues : personne ne peut les récupérer.

## Versions
- **Gratuite** : coffre, générateur de mots de passe, corbeille, 6 styles de couleurs, 3 fonds.
- **Pro** (licence) : tous les styles et la couleur libre, 11 fonds animés en plus, icônes, audit des mots de passe, sauvegardes automatiques.

## Compiler soi-même
Mets `MonCoffre.cs` (et `MonCoffre.ico` si tu en as un) dans un dossier avec `Creer-MonCoffre.bat`, puis double-clique sur le `.bat`. Aucune installation n'est nécessaire (le compilateur est déjà dans Windows).
